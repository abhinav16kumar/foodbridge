# Contributing to FoodBridge

Thank you for your interest in contributing to FoodBridge.

## How to contribute

1. Fork the repository.
2. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes.
4. Test the application locally.
5. Commit your changes:
   ```bash
   git add .
   git commit -m "Add: your feature description"
   ```
6. Push to your branch:
   ```bash
   git push origin feature/your-feature-name
   ```
7. Open a pull request.

## Code style

- Use clear and descriptive variable names.
- Keep components small and reusable.
- Follow the existing project structure.
- Do not commit environment variables or secrets.
- Test API endpoints before submitting changes.

## Reporting issues

If you find a bug or want to suggest an improvement, open a GitHub issue with:

- A clear title
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Screenshots, if applicable
